**⚠️ Stream isolation confirmed:** Two different Tor exit IPs returned simultaneously
for different destination hosts through the same SOCKS5 proxy. This is Tor's default
stream isolation behavior — each destination gets its own circuit. Both confirmed the
rotation (pre-rotation `check.torproject.org` IP was 45.84.107.97; post-rotation it's
185.181.61.203), but the `api.ipify.org` IP (192.42.116.142) shows a third circuit.

**Diagnostic lesson:** Always compare the SAME service before and after rotation. If you
check `check.torproject.org` before and `api.ipify.org` after, you'll see a meaningless
comparison affected by stream isolation.
