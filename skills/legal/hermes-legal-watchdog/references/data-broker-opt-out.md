## Critical: PeopleConnect Dual Opt-Out

TruthFinder and Instant Checkmate require **two separate steps**:
1. **User Data deletion** — via their privacy center forms
2. **Public Data suppression** — via suppression.peopleconnect.us portal

If only one step is completed, data will still appear.

## Reappearance Cycle

Most data brokers re-add data every 30-90 days if a new data aggregator feeds them.
- The weekly Reputation Monitor (Sat 10AM) checks for reappearances
- If data reappears, re-file the opt-out and escalate if it happens twice

## Legal Options for Non-Compliance

If a site refuses removal or re-adds data repeatedly:
1. Send formal cease & desist (template in repo's legal-notices/)
2. File FTC complaint (reportfraud.ftc.gov)
3. State attorney general complaint
4. Defamation lawsuit if false content persists
