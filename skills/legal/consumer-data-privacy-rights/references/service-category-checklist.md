# Service Category Discovery Checklist

Use this checklist to prompt the user when building or expanding the service registry.
Go category by category — each category has specific discovery prompts.

## 1. Social Media & Communication
- [ ] Discord (guilds, messages, payment info)
- [ ] Telegram (messages, contacts)
- [ ] X/Twitter (posts, DMs, analytics)
- [ ] Reddit (posts, comments, voting)
- [ ] GitHub (code, commits, repos, profile)
- [ ] LinkedIn (profile, messages, connections)
- [ ] Signal / WhatsApp (messages, contacts)

## 2. Cloud & Productivity
- [ ] Google Workspace / Gmail (emails, docs, calendar, drive)
- [ ] Microsoft / Outlook / OneDrive
- [ ] iCloud / Apple ID
- [ ] Notion (notes, databases, projects)
- [ ] Obsidian Sync
- [ ] Linear (issues, projects)
- [ ] Dropbox / Box

## 3. AI & Development Tools
- [ ] OpenAI / ChatGPT (chats, API usage)
- [ ] Anthropic / Claude (API usage, prompts)
- [ ] OpenRouter (API usage, keys)
- [ ] GitHub Copilot/Chat (code snippets, usage)
- [ ] FAL.ai (generated images, account)
- [ ] HuggingFace (models, datasets, usage)
- [ ] Replit / Gitpod (code, projects)
- [ ] Vercel / Netlify (deployments, domain info)

## 4. Financial & Payment
- [ ] Bank accounts (transactions, statements)
- [ ] Credit cards (purchases, billing)
- [ ] PayPal / Venmo (transactions, linked accounts)
- [ ] Stripe (payment processing data)
- [ ] Coinbase / Crypto exchange (KYC, trading)
- [ ] Robinhood / Brokerage (holdings, trades)
- [ ] Mortgage / Loan provider

## 5. Email & Marketing Tools
- [ ] Mailchimp / ConvertKit / ActiveCampaign
- [ ] Postiz (scheduled posts, social accounts)
- [ ] Airtable (databases, records)
- [ ] HubSpot / Salesforce

## 6. Business & CRM
- [ ] Twenty CRM (contacts, deals, notes)
- [ ] Gumroad (product listings, customers)
- [ ] ChocoData / Real estate data providers

## 7. Travel & Hospitality
- [ ] Airbnb (booking history, messages)
- [ ] Hotels.com / Booking.com / Expedia
- [ ] Hotel chains (Marriott, Hilton, Hyatt, etc.)
- [ ] Airlines (Delta, United, American, Southwest)
- [ ] Uber / Lyft (ride history, location data)
- [ ] Hertz / Enterprise / Car rental
- [ ] TSA PreCheck / Global Entry / Clear
- [ ] Amtrak / Train services

## 8. E-Commerce & Retail
- [ ] Amazon (purchases, browsing, Alexa)
- [ ] Apple App Store / iTunes
- [ ] Walmart / Target / Home Depot
- [ ] Best Buy / Newegg
- [ ] eBay / Etsy
- [ ] Grocery delivery (Instacart, FreshDirect)

## 9. Streaming & Entertainment
- [ ] Spotify (listening history, playlists)
- [ ] Netflix / Hulu / Disney+
- [ ] Apple Music / TV+
- [ ] YouTube Premium / Music
- [ ] Twitch
- [ ] Patreon / Substack

## 10. Healthcare & Insurance
- [ ] Health insurance provider
- [ ] Dental / Vision insurance
- [ ] Pharmacy (CVS, Walgreens)
- [ ] Doctor / Healthcare provider portals
- [ ] Life insurance
- [ ] Pet insurance

## 11. Telecom & Utilities
- [ ] Phone carrier (Verizon, T-Mobile, AT&T)
- [ ] ISP (Spectrum, FIOS, Comcast)
- [ ] Electric / Gas utility
- [ ] Water / Sewer
- [ ] Trash / Recycling service
